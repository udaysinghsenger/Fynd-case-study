# StyleBazaar → Fynd Catalog Migrator

Private Fynd extension for transforming and ingesting legacy StyleBazaar catalog data into the Fynd Commerce Platform.

---

## Features

- Legacy → Fynd field mapping
- Product validation
- Category mapping
- Variant/size normalization
- Error logging
- Fynd Catalog API integration

---

## Run Locally

```bash
npm install
fdk extension preview
